CSS Position

A complete practical tutorial covering static, relative, absolute, fixed, sticky, offsets, z-index, and a real navbar project.

What Is CSS Position?

The CSS position property determines how an element is positioned within a webpage.

The five major values are:

  • static
  • relative
  • absolute
  • fixed
  • sticky

A very important question to ask when learning positioning is:

"Positioned relative to what?"

1. position: static

static is the default positioning value for HTML elements.

HTML Example 

<div class="static-example">
    Static
</div>
Static

CSS Applied 

.static-example {

    position: static;

    width: 150px;
    height: 80px;

    display: flex;
    align-items: center;
    justify-content: center;
}

The element remains in the normal document flow.

Important: static is the default value.

2. position: relative

Relative positioning keeps the element in the normal document flow but allows you to visually offset it.

HTML Example 

<div class="relative-example">
    Relative
</div>
Relative

CSS Applied 

.relative-example {

    position: relative;

    top: 30px;

    left: 40px;
}

top: 30px moves the element 30 pixels downward.

left: 40px moves the element 40 pixels to the right.

Very Important Use of Relative

Relative positioning is frequently used to create a positioning reference for an absolutely positioned child.

3. position: absolute

Absolute positioning removes the element from normal document flow.

HTML Example 

<div class="absolute-example-area">

    <div class="absolute-example">
        Absolute
    </div>

</div>
Absolute

CSS Applied to Parent 

.absolute-example-area {

    position: relative;

    min-height: 250px;
}

CSS Applied to Child 

.absolute-example {

    position: absolute;

    top: 20px;

    right: 20px;
}

Because the parent has position: relative, the absolute child is positioned relative to that parent.

4. position: fixed

Fixed positioning attaches an element to the browser viewport.

HTML Example 

<div class="fixed-example">
    Fixed
</div>

Look at the bottom-right corner of your browser. You should see the actual example:

Fixed

CSS Applied 

.fixed-example {

    position: fixed;

    bottom: 25px;

    right: 25px;
}

Scroll the page.

The element remains attached to the browser viewport.

This is why fixed positioning is frequently used for floating buttons, navigation bars, chat buttons, and similar interface elements.

5. position: sticky

Sticky positioning allows an element to behave normally until a specified scrolling threshold is reached.

HTML Example 

<div class="sticky-example">
    Sticky
</div>
Sticky Element

CSS Applied 

.sticky-example {

    position: sticky;

    top: 20px;
}

Continue scrolling to observe its behaviour.

6. The top Property

The top property controls the distance from the top edge.

HTML Example 

<div class="top-example">
    Top
</div>
top: 30px

CSS Applied 

.top-example {

    position: relative;

    top: 30px;
}

7. The right Property

The right property controls the distance from the right side.

HTML Example 

<div class="right-example">
    Right
</div>
right: 30px

CSS Applied 

.right-example {

    position: relative;

    right: 30px;
}

8. The bottom Property

The bottom property controls the distance from the bottom edge.

HTML Example 

<div class="bottom-example-area">

    <div class="bottom-example">
        Bottom
    </div>

</div>
bottom: 20px

.bottom-example-area {

The left property controls the distance from the left edge.

10. z-index

z-index controls the stacking order of positioned elements when they overlap.

HTML Example 

<div class="z-index-area">

    <div class="z-box-one">
        z-index: 1
    </div>

    <div class="z-box-two">
        z-index: 2
    </div>

</div>
z-index: 1
z-index: 2

CSS Applied to First Element 

.z-box-one {

    position: absolute;

    z-index: 1;
}

CSS Applied to Second Element 

.z-box-two {

    position: absolute;

    z-index: 2;
}

Since 2 is greater than 1, the second box appears above the first box.

11. Relative Parent + Absolute Child

This is one of the most important patterns in CSS positioning.

HTML 

<div class="relationship-parent">

    <div class="relationship-child">
        Absolute Child
    </div>

</div>
Parent: position: relative
Absolute Child

Parent CSS 

.relationship-parent {

    position: relative;
}

Child CSS 

.relationship-child {

    position: absolute;

    top: 20px;

    right: 20px;
}

The child is positioned relative to the parent.

You will see this pattern in dropdown menus, notification badges, profile indicators, cards, image overlays, and many other interfaces.

Position Values Compared

Position Normal Flow? Typical Use
static Yes Normal elements
relative Yes Reference point / small offsets
absolute No Dropdowns / badges / overlays
fixed No Floating or viewport-attached UI
sticky Yes Sticky navigation
